**Status column**

| Code | Meaning |
|---|---|
| **V** | Verified — figure read on the cited page |
| **V2** | Verified on a secondary page (e.g., a newspaper reporting an official release); the primary document was not opened |
| **S** | Search-snippet only — not used as an [F] fact; used only to support estimates, with the limitation disclosed |
| **L** | Marketplace or company price listing — indicative asking price, not a market average |

| **S/L** | Listing seen only in a search snippet (site blocked direct reading) |

**Tier:** 1 = official Ghanaian body · 2 = multilateral / research · 3 = credible media / industry · 4 = listing / company site. See [research-methodology.md](../research/research-methodology.md#3-source-hierarchy). Where a newspaper reports an official release, the tier reflects the **original** publisher and the status is **V2**.
