# Data Dictionary

[← Back to README](../README.md) · Sources and citations: [sources.md](sources.md)

All datasets are plain CSV (UTF-8) so they can be opened in Excel, Google Sheets or pandas. **Inputs** are hand-compiled from the research and carry a `basis` and `source_ref` column. **Outputs** are generated by the scripts in [`models/`](../models/) and should not be edited by hand.

## Inputs — `datasets/inputs/`

| File | One row per | Key columns |
|---|---|---|
| `global_assumptions.csv` | Model-wide parameter | `parameter`, `value`, `unit`, `basis`, `source_ref` (FX rate, tax rates, thresholds, contingency rate) |
| `businesses.csv` | Shortlisted business | `business_id` (SOL, LAU, BRO, DEL, DIG), `short_name`, `legal_form`, `tax_mode` (`cit` or `turnover`), `tax_rate`, `vat_status` |
| `startup_costs.csv` | Startup budget item | `category` (one of 8 categories; contingency is calculated), `amount`, `currency` (GHS/USD), `useful_life_months` (blank = not depreciated/amortised), `basis`, `source_ref` |
| `revenue_drivers.csv` | Revenue line × parameter | `line`, `parameter` (`price`, `unit_cost`, `steady_volume`, `start_month`, `ramp_months`, `monthly_growth`), `conservative`, `base`, `optimistic`, `currency` |
| `operating_costs.csv` | Operating cost line | `cost_type` (`payroll_month` + SSNIT, `fixed_month`, `variable_pct_revenue`), scenario values, `currency` |
| `opportunity_screening.csv` | Long-list opportunity | Five criterion scores (1–5), `screening_score` (validated as their mean), `gate_result`, `decision`, `evidence_refs` |
| `scoring_weights.csv` | Ranking criterion | `weight_recommended`, `weight_equal`, `weight_risk_averse` (each set sums to 1) |
| `scoring_qualitative.csv` | Business × analyst-scored criterion | `score`, `rationale`, `evidence_ref` |
| `risk_register.csv` | Risk | `category`, `likelihood` (1–5), `impact` (1–5), `mitigation`, `evidence_ref` |

**`basis` values:** `Verified fact` (read at the cited source) · `Estimate` (derived from verified data) · `Listing` (marketplace/company asking price) · `Assumption` (analyst judgement, stress-tested).

## Outputs — `datasets/outputs/`

| File | Contents |
|---|---|
| `monthly_projections.csv` | 5 businesses × 3 scenarios × 12 months: revenue, COGS, gross profit, fixed/variable opex, EBITDA, D&A, net operating profit, tax, net profit, operating cash flow, cumulative cash flow, cash balance, units per revenue line |
| `summary_metrics.csv` | One row per business × scenario: investment, year-1 totals, ROI (year-1 and run-rate), break-even month, break-even revenue, contribution margin, payback, lowest cash balance |
| `investment_breakdown.csv` | Startup budget by category (USD and share) |
| `sensitivity_analysis.csv` | ±20% price/volume/unit-cost/fixed-cost shocks and the FX stress test |
| `screening_robustness.csv` | Stage 2 long-list ranking under four alternative weightings |
| `criterion_scores.csv` | All seven criterion scores per business with rationale |
| `weighted_ranking.csv` | Final weighted scores and ranks |
| `ranking_robustness.csv` | Ranks under the three weight sets |
| `tables/*.md` | Markdown tables injected into the write-up by `report_tables.py` |

## Reproducing

```bash
pip install -r requirements.txt
python models/run_all.py
```

The pipeline validates itself as it runs: it stops if a startup budget leaves the US$5,000–20,000 range, if a cost type or category is unknown, if a screening score is not the mean of its criteria, if a weight set does not sum to 1, or if a document refers to a table that does not exist.
